## 版本说明

补齐旧主世界通道的 Promise 能力探测，避免同步探测通过而真实调用返回缺失哨兵。

## 主要变更

- 探测使用与真实执行一致的异步返回形式，识别仅支持同步返回的旧通道。
- 不支持时提前选择 `wrappedJSObject`，保持用户代码最多执行一次。

## 兼容性

- 默认 isolated、工具参数与既有 API 不变，无需重编浏览器；Skill v3.6.1 可继续使用。
- 推荐 152 reverse.5；旧构建的主世界回退仍以运行时探测结果为准。

## 验证

- 新增同步通道可用、Promise 返回被丢弃的回归场景，验证回退成功且用户代码只执行一次。
- 完整测试 `190 passed, 1 skipped`；真实 152 reverse.5 的主世界、Frame、Trace 清理与卸载场景复验通过。
