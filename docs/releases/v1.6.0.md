## 版本说明

完善通用请求采集与独立验签，修复证据关联和 Cookie 操作边界，保留现有工具名与默认调用方式。

## 主要变更

- 按原始 Request 对象关联并发响应，补齐 Cookie/Set-Cookie、请求失败、缓冲区淘汰、正文截断和采集任务清理。
- 新增增量分页与 JSON 采集导出，默认掩码敏感内容，明确 pending、丢弃和截断状态，避免将残缺数据当完整证据。
- Cookie 名称与域名条件取交集；验签拒绝无有效断言的样本，新增可选 Node.js 独立运行时和有界执行，默认浏览器路径保持兼容。
- 补充通用采集与真实本地浏览器回归，将新测试加入三平台 CI，并在更新既有 Release 前校验 tag 与成功 CI 的提交一致。

## 兼容性

- 保留 Python 3.10+、Camoufox 0.4/0.5 与 Playwright 1.40+ 的声明范围；旧 Playwright 的定向 Cookie 删除通过仅过期选中条目实现。
- 默认 browser 验签、已有网络工具与列表返回形状保留；新增 export 工具、分页参数与 runtime=node 为可选能力。清理捕获不再复用请求 ID；域名过滤采用真实主机边界。
- Node runtime 需要 Node.js；BrowserContext 里已有 Hook 不受本轮采集改动影响，不要求重编定制浏览器。

## 验证

- 本地完整测试（含真实浏览器用例）222 passed、1 skipped；默认离线集合对应 221 passed、2 skipped。
- 真实 Camoufox 152.0.4-beta.30 访问本地 HTTP fixture，验证同 URL 并发响应、完整 Set-Cookie、正文截断和定向 Cookie 删除通过。
- 不将本地 fixture 验证等同于真实目标站点的长期稳定性验证。
