## 版本说明

修复 v1.5.0 的 Trace 清空后调用异常，并完善主世界执行、未来 Frame 与 Hook 卸载边界。

## 主要变更

- 清空 Trace 后仍可继续调用被追踪函数，保持返回值和页面行为。
- 主世界通道先探测再执行；执行失败不自动重放用户代码，避免副作用重复发生。
- 持久 Hook 可预先注册尚未创建的目标 Frame，以 `pending` 区分注册和实际安装。
- 当前 Frame 的 Hook 和等待器可显式卸载；无法恢复的锁定属性按实际结果报告。

## 兼容性

- 默认 `world="isolated"`、既有工具参数和 PropertyTracer protocol 1 保持兼容。
- 本次为 MCP 修复，无需重新编译 Camoufox。
- Playwright 已注册的初始化脚本无法直接注销；彻底移除持久 Hook 仍需关闭并重新启动浏览器。
- Attach 模式仅断开 MCP 连接不会销毁外部浏览器；应实际重建外部 BrowserContext 或浏览器。

## 验证

- 回归覆盖清空后再次调用、单次执行副作用、未来 Frame 和 Hook 卸载行为。
- 本地完整测试 `189 passed, 1 skipped`，其中 42 项主世界、Frame 与 Hook 专项测试通过。
- 真实 Camoufox 152 reverse.5 验证默认隔离、清空后继续调用、未来 iframe 首次调用、跨 Frame 卸载、继承属性恢复及冻结等待器的部分移除状态。
