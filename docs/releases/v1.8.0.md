## 版本说明

通过真实 GitHub VM、混淆器、加解密与指纹 SDK 的本地多轮实操，修复观测改变业务结果、主世界日志漏读及数据返回失真的问题。

## 主要变更

- 源码插桩保留异常、this 和求值顺序，使用低副作用预览与确定性抽样；新增本地 Acorn 现代语法解析，保守跳过不支持场景，去除未经测量的覆盖率承诺。
- 插桩日志支持主世界和指定 Frame，过滤覆盖方法与静态对象路径；动态响应按当前内容缓存，失败不重复发送请求，报告跳过、容量与解析后端。
- evaluate_js 新增 json_ascii 精确字符串传输；函数 trace 新增 preview 序列化及同步抛错记录，不自动重放表达式或观察 Promise 完成。
- 原生快照明确页面/世界与事件归属边界；新增真实上游案例、独立验收记录与跨平台回归。

## 兼容性

- 保持工具名、旧参数及默认 evaluate_js(auto)、hook_function(json)；新选项按需启用。对象源码日志改为类型占位以减少观测副作用。
- esprima 保留；现代语法回退需要本地 Node。Acorn 与 MIT 许可随 MCP 打包，无页面 CDN、无输入源码执行。保守跳过可能使日志数量下降，请检查 files_rewritten/last_skip_reason。
- 不要求修改持久浏览器版本或启用原生 trace。原生 77 点是固定 DOM/Web API 范围，不包含任意 JS 对象或 VM opcode；快照不是事件时值。

## 验证

- 本地完整离线回归 422 passed、2 skipped；另启用真实浏览器采集集成测试 1 项通过；公开脚本通过 6 个真实 MCP 浏览器场景及定制浏览器原生 trace。
- 真实 KProtect/CFF 新输入独立验收 40/40；CryptoJS 与独立 Node/Python 交叉验收及本地风险反例通过；指纹同 profile、描述符、多窗口、容量与实例隔离实测通过。
- 第四个新上下文 Agent 对冻结修复候选执行 60 次真实 MCP 协议操作（其中 58 次工具调用，含两次自有浏览器关闭），33 项证据断言全部通过；维护者独立重跑。失败分支与模型反馈均保留。详见[真实源码验证记录](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/blob/v1.8.0/docs/REAL_SOURCE_VALIDATION.md)。不宣称商业站点或长期压测通过。
