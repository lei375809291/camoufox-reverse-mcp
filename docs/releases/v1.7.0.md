## 版本说明

通过公开源码研究和三轮独立 Agent 实操，完善通用请求证据与任务级诊断，保持现有工具名和默认采集行为。

## 主要变更

- 新增请求差异对比与响应文件保存：保留重复 query/原始正文，区分规范 JSON 摘要与实体字节哈希，不补抓、不覆盖文件，默认拒绝残缺字节。
- 环境检查按任务范围报告状态与分项能力，保留已有证据；初始化版本统一为应用版本，明确调用栈归因的启发式边界。
- 保留真实导航错误，快照增加有界等待和输出上限，明确字符/字节、来源与截断状态，避免错误页诊断阻塞。
- 补充回归、三平台检查和公开研究/行为评测记录，保留第二轮失败及后续恢复，不将单元测试当作真实任务验收。

## 兼容性

- 既有工具名、网络捕获与验签默认行为保留，新增工具和参数为可选；take_snapshot 默认最多等待5秒，可用 timeout_ms 调整至30秒。
- 保持 Python 3.10+、MCP SDK v1、Camoufox 0.4/0.5 兼容范围，不要求重编浏览器或启用原生 trace。
- 对比与导出的字节是 HTTP 解压后的实体；不是压缩传输线字节。状态指纹不是完整页面/鉴权/SDK校验。

## 验证

- 本地完整回归含真实浏览器：243 passed、1 skipped；默认离线集合242 passed、2 skipped。
- 三轮九个独立Agent任务，最终一轮签名/WASM/分页全部通过隐藏的新输入验收。前轮的环境阻塞及脚本错误保留，方法与边界见研究记录。
- 真实MCP拒绝连接、错误页快照、恢复导航和保留捕获复测通过；不宣称商业站点或长期压测成功率。
